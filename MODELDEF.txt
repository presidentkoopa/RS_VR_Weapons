// ============================================================================
// RS_VR_Weapons -- WHAT EACH TEST GUN IS DRAWN AS.
//
// GZDoom decides model-vs-sprite from MODELDEF, per class, so each prop class
// has a block here and its card names it (`prop`). The meshes and skins are this
// package's own copies (models/pistols/, models/shotguns/). The shotgun meshes
// are byte-identical to RS_ModelSwapper's re-centred ones as of 2026-09-12.
// Nothing here depends on RS_ModelSwapper.
//
// SCALE AND OFFSET: RS_ModelSwapper's own HUD blocks for these meshes, verbatim
// (its modeldef: the pistols' blocks, MS_AE_Shotgun and MS_Shotgun). An Offset
// belongs to ONE mesh's origin and never transfers to another mesh; where the
// hand holds it is the placement set on top -- the reload system's per-hand seats
// (wm_main / wm_off, its CVARINFO) for the pistols, this package's own sets
// (CVARINFO.txt) for the shotguns.
//
// WHERE THE GRIP LANDS -- AN ESTIMATE, COMPUTED, NOT SEEN IN A HEADSET. On the
// follow-hand path (models.cpp) the placement yaw of -90 turns the mesh, then
// Offset and the placement offsets are added, then it is scaled: the same chain
// RS_ModelSwapper's tools_md3_compensate.py replicates for the HUD path. So
// Offset y runs along the barrel (minus md3 x, times Scale) and z is up. With the
// pistols' seats (the wm_main / wm_off defaults):
//
//   M37A2         its pistol grip (-26.5, 0, -8.5) lands 1.3 map units BEHIND
//                 the M4A3's grip (its magazine centroid), and level with it.
//   Doom shotgun  its wrist (-13, 0, -1.0) lands 0.7 map units behind and 1.4
//                 ABOVE the Pistolet's grip -- a straight stock's wrist is
//                 higher than a pistol grip hangs.
//
// If either sits wrong, the Offset that puts that grip squarely on its pistol's
// is: M37A2 `Offset -0.257 -53.01 -5.625`; Doom shotgun `Offset 0.042 -43.88 -8.05`.
//
// MIRRORED: the M37A2's Scale x is -1.1, as the M4A3's is -0.82. On this path the
// mesh is turned before it is scaled, so x scale acts ACROSS the gun: mirrored
// left for right, never front for back. NOAUTOREVERSE on every gun: a gun in your
// left hand is still that gun, not its mirror image.
//
// FrameIndex WMPR: the reload system's one-pixel prop sprite, which every
// WM_Prop's Spawn state shows.
// ============================================================================

// ----------------------------------------------------------------------------
// A MAGAZINE, AND A ROUND. WM_LooseMag and WM_LooseRound are the RELOAD SYSTEM'S
// classes (its loose.zs); these blocks are here because their default meshes are
// pistol assets, and a gun's assets are this package's. Without this package the
// two classes have no block and draw as their placeholder sprites (WMMG / WMRD).
// Moved from the reload system's MODELDEF on 2026-09-12, verbatim but for Path.
//
// ONE PACKAGE ONLY may carry these two blocks: a second MODELDEF block for the
// same class elsewhere in the load order would fight this one.
//
// The mesh here is only the bootstrap: the card names the real one and
// A_ChangeModel swaps to it on spawn, so a gun's magazine is its own and another
// gun needs no edit to this file. (A shotgun's shell is its card's roundmodel.)
//
// SCALE 1 HERE, ON PURPOSE. MODELDEF Scale and the actor's own Scale MULTIPLY;
// the card owns the number, and two writers on one scale is how a magazine ends
// up the size of a bullet.
//
// USEACTORPITCH AND USEACTORROLL, without which it cannot tumble or lie down: a
// model ignores an actor's pitch and roll unless it opts in.
//
// Their PlacementCVars are the reload system's default floor sets (wm_ha_default_floor_mag /
