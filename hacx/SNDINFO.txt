// ==========================================================================
// THE HACX SET'S SOUNDS.
//
// A SET SHIPS ITS OWN SNDINFO the same way it ships its own MODELDEF: SNDINFO ACCUMULATES
// across archives rather than replacing, so this sits beside the base pack's instead of
// standing in for it. Nothing here restates a name the base already owns.
//
// THE SOURCE MOD'S OWN, out of the same pack the meshes come from, so they travel under the
// same credit. Nothing is borrowed from another set: where this mod recorded no sound for a
// step, the step is left out rather than filled with a neighbour's, because a pistol's slide
// standing in for a rifle's bolt is worse than silence -- it sounds deliberate.
//
// RELOAD FOLEY IS NAMED HERE BUT WIRED IN WMCARD.hacx, which is the reload lane's file. A
// Weapon Card owns exactly one sound key, `firesound`. Everything below that the guns do not
// fire with is listed so their cards have names to point at.
// ==========================================================================
