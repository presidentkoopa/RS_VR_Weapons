// ==========================================================================
// RS_VR_BD22 -- THE SET'S OWN RELOAD FOLEY.
//
// THE SOUNDS ARE BRUTAL DOOM'S OWN, harvested from brutal22test6.pk3, the pack these
// guns come from. Nothing is borrowed from a neighbouring set: this set is standalone
// and has to be audible with nothing loaded but Doom beside it, so it carries its
// files rather than naming another pack's.
//
// THE NAMES ARE OURS (`bd22/...`) AND NOT BRUTAL DOOM'S. Declaring `Pistol/Reload1`
// here would collide with the mod's own SNDINFO the moment both are loaded, and the
// last definition would win -- silently, and differently depending on load order.
// Under our own names both sets of sounds exist side by side and neither moves.
//
// FIRE SOUNDS ARE NOT HERE. A weapon card owns exactly one sound key, `firesound`,
// and the rest of a gun's voice is the weapon sheet's. Stating a fire sound in two
// places is how a card and a sheet come to disagree.
// ==========================================================================
