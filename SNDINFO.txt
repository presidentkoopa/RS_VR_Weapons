// BARE LUMP NAMES, NOT PATHS.
//
// Anything under sounds/ is put in ns_sounds by the file system, and the name
// it is registered under is the BASE FILENAME with the path and extension
// stripped (filesystem.cpp:134 for the namespace, :157 for the short name). So
// sounds/rs_grenade/DSGRPIN is looked up as DSGRPIN, and the full path does not
// match. RS_Main writes the path form and gets away with it via the
// full-name fallback, but the short name is the one this lookup is built on.
rsvg/pin      DSGRPIN
rsvg/toss     DSGRTOSS
rsvg/bounce   GBOUNCE
rsvg/farexpl  FAREXPL
rsvg/tick     GPIN
