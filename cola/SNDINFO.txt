// ==========================================================================
// THE COLA 3 SET'S SOUNDS.
//
// A SET SHIPS ITS OWN SNDINFO the same way it ships its own MODELDEF: SNDINFO ACCUMULATES across
// archives rather than replacing, so this sits beside the base pack's instead of standing in for
// it. Nothing here restates a name the base already owns.
//
// COLA 3'S OWN, out of the same pack the meshes come from, so they travel under the same credit.
// 118 files came across with the models; this names the ones the eight guns use.
//
// THE SET WAS REPORTED AS SHIPPING ZERO AUDIO OF ANY FORMAT. It ships 118 files, 2.37 MiB, and
// they were already in sounds/cola/ when that was said -- the scan had been run against the
// models-only checkout rather than against the mod. Worth keeping next to the note in the Aliens
// SNDINFO, which is the same error in the opposite direction: there a scan of the right archive
// matched on file extension and missed sixty-six lumps that had none.
//
// THE FOLDER NAMES ARE THE MOD'S OWN AND THEY NAME THE GUNS. piledriver/ is the Jackhammer,
// toothpastelaser/ is the Particle Gun, missilelauncher/ is the Sidewinder. Two of us mapped
// these independently and landed identically, which is the strongest evidence either of us has
// that the mapping is right -- there is no manifest to check it against.
//
// RELOAD FOLEY IS NAMED HERE BUT WIRED IN WMCARD.cola, which is the reload lane's file. A Weapon
// Card owns exactly one sound key, `firesound`. Everything below that the guns do not fire with
// is listed so their cards have names to point at.
// ==========================================================================
