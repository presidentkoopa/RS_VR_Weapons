# ============================================================================
# THE TEST GUNS: two pistols and two pump shotguns, one of each per hand.
#
# Each card says only what that gun is: where its parts are and how far they
# move, its stores, its meshes and sounds. What a TYPE of gun does with those
# parts is the reload system's (RS_VR_Reload/WMCARD.txt), taken with
# `mechanism = <archetype>`. What a trigger pull puts in the air is the weapon
# CLASS's (WM_Gun.ShotPellets / ShotSpread / ShotDamage, zscript/rs_vr_weapons/),
# not the card's. Read from every WMCARD lump in the load order.
#
# CARD ORDER IS SPAWN ORDER. For a second after you spawn the reload system puts
# each carded gun into its hand, in card order (system.zs Equip), so the pistols
# come first: they are the guns raised when you spawn. WM_PumpTestHandler then puts
# the shotguns in hand (zscript/rs_vr_weapons/loadout.zs, wm_pump_start_in_hands).
#
# EVERY MESH NUMBER IS MEASURED, NOT GUESSED, and each says how:
#
#     python E:\DOOMWork\tools\md3.py MODEL            -- structure
#     md3.part_motion(model, part, ref)                 -- travel, turn, fit error
#     python E:\DOOMWork\tools\md3_write.py extract ... -- the loose magazine / shell
#
# Rigid fit with the receiver's own motion divided out (the receivers of the
# pistols and both shotgun meshes move in their reload frames). Frames where a
# part is collapsed to a point (pistolet's magazine at 12-14, its second piece at
# 7-14) are flagged `degenerate` and never measured from. The few numbers that are
# NOT measured say ESTIMATE, and why.
#
# ALL POINTS AND AXES ARE MD3 MODEL SPACE: x along the barrel toward the
# muzzle, y across, z up, in the mesh's own units. The system converts to the
# renderer's own axes (which swap y and z) at the one place that needs it.
# Grab radii and oval half-sizes are MAP units.
#
# SCALE, for turning mesh units into map units: MODELDEF Scale x 0.34, the
# controller frame's own ratio. M4A3 0.82 x 0.34 = 0.279; M37A2 1.1 x 0.34 =
# 0.374; Doom shotgun 1.35 x 0.34 = 0.459.
# ============================================================================


# ============================================================================
# THE PISTOLS. Moved here from the reload system on 2026-09-12 with every number
# and comment unchanged; only the mesh paths moved (models/ -> models/pistols/).
#
# THE MAGAZINE MOVES STRAIGHT. Both meshes animate a tilt as the magazine
# leaves -- but a magazine inside its well cannot turn; the tilt is free fall,
# after it has cleared. So the axis is the one measured from the INSERT frames,
# where the motion is a pure translation, and the distance is the magazine's
# own length along it: how far your hand pulls before it is free.
#
# NO MECHANISM AND NO VERBS: each pistol's slide cycle and magazine swap are
# synthesised from its `role = action` and `role = feed` parts (card.zs
# SynthesiseVerbs). EVERY SOUND IS STATED -- the reload system names no gun's
# sounds, so a moment a card leaves out is silent.
# ============================================================================

  # the gun was. magscale 0.279 = the gun's 0.82 x 0.34 (the follow-hand

  roundskin  = "models/pistols" "bullet.png"
  roundscale = 0.175

  firesound      = "wm/m4a3/fire"

# ============================================================================
# THE REVOLVERS: two break-tops and a swing-out, on the reload system's
# `breaktop_revolver` and `swingout_revolver` archetypes (RS_VR_Reload/WMCARD.txt).
#
# The archetype says what a revolver of that kind DOES -- open, throw the cases
# out, take a speedloader, shut, fire a chamber a pull. Each card says where its
# own parts are and how far they move. Surveyed and measured in
# REVOLVER_CANDIDATES.md; every number below says how it was got.
#
# THE CYLINDER IS THE CHAMBER. A slotted, indexed store that turns on the shot:
# each trigger pull fires the chamber under the hammer and turns the next one
# round -- on a click too. It is the gun's only store, so the trigger fires from
# it and nothing else (WM_Ammo's facade takes the first slotted store).
#
# THE SPEEDLOADER IS THE AMMO IN YOUR HAND. The pouch hands a revolver a loader
# of up to its capacity, drawn as the card's magmodel and held on the
# held-magazine sliders; let go of at the open cylinder's face, it fills every
# empty chamber at once. A single loose round fills one.
# ============================================================================


# ============================================================ MOONLIGHT -- MAIN HAND
# rev.md3, first skin. A BREAK-TOP: the barrel (python.007) and the cylinder
# (python.005) move as one rigid assembly (pooled rigid fit rmsd 0.094) on one

# rounds (python.008-013) put INTO the cylinder at rest. In rev.md3 they are
# collapsed to a point at frame 0 and only exist in frames 20-29, the donor's
# reload. Their frame-20 geometry -- seated in the chambers, measured against the
# cylinder's own motion (fit 0.093) -- was carried back into the cylinder's rest
# frame and pushed home so each rim stands 0.17 proud of the rear face (x -1.28).

# THE VERBS, DECLARED. A two-stage part's thresholds read the COMBINED pull, so the
# pistol grammar's synthesised rack (outat 0.6) would count at 20% of the slide,
# just past the fold. Declaring a verb turns synthesis off, so the magazine's swap
# is declared too, with the synthesised swap's own numbers. The stores are still
# the synthesised pair: `mag` and `chamber`.
#
# THE RACK: the pistol slide's synthesised cycle, but counted at 0.85 -- the fold
# and 70% of the slide. auto = onshot, as every self-loading gun here: the shot
# ejects and feeds, and the handle is drawn working on each shot. A real Vector's
# handle does not move when it fires; `none` would make it a rack per shot.
cycle rack
  part     = charginghandle
  outat    = 0.85
  apex     = 0.95
  # homeat 0.10 off: refused on a return = spring cycle, which skipped this whole card (the invisible SMG, 09-14)
  onout    = eject
  from     = chamber
  onhome   = feed
  feed     = mag
  into     = chamber
  return   = spring
  holdopen = whenempty
  auto     = onshot
end

  handtake = no
end
