// ==========================================================================
// THE ALIENS SET'S SOUNDS.
//
// A SET SHIPS ITS OWN SNDINFO the same way it ships its own MODELDEF: SNDINFO ACCUMULATES across
// archives rather than replacing, so this sits beside the base pack's instead of standing in for
// it. Nothing here restates a name the base already owns.
//
// ALIENS ERADICATION'S OWN, out of the same pack the meshes come from, so they travel under the
// same credit. Not one sound here is borrowed from another set.
//
// THE SET WAS REPORTED AS HAVING ONE WEAPON SOUND. It has seventy. Both of us went looking and
// both of us came back with a number that was wrong in the same way: a lane scanned the models
// repo instead of the mod and found no audio at all, and I then scanned the mod but matched on
// FILE EXTENSION -- and Aliens Eradication stores its sounds as classic Doom lumps with no
// extension at all. Four of its seventy end in .ogg or .wav, so four is what I reported. The
// owner put the extracted SOUNDS/WEAPONS folder in front of me and the other sixty-six were
// sitting in it.
//
// That is the seventh shape in build.ps1's header -- a tool reporting an absence it could not
// actually see -- and it is worth reading twice, because BOTH of us hit it inside an hour on the
// same set. When a set looks silent, it is far likelier that the question was wrong.
//
// RELOAD FOLEY IS NAMED HERE BUT WIRED IN WMCARD.aliens, which is the reload lane's file. A
// Weapon Card owns exactly one sound key, `firesound`. Everything below that the guns do not fire
// with -- the clips, the pump, the bolt, the dry click -- is listed so their cards have names to
// point at.
// ==========================================================================
