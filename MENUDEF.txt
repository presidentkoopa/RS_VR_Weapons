// ============================================================================
// RS_VR_Weapons -- the test shotguns' options, laid out like the pistols' page
// in the reload system: a page per gun, then the shared pages (hands, ovals,
// rounds, pouch, firing) that work for whatever gun is in your hand.
//
// Added to the engine's own OptionsMenu, not to the reload system's page: an
// AddOptionMenu naming a menu that does not exist stops the engine at startup,
// and this package must never be able to do that to the reload system. The
// Submenu links below only open the reload system's pages, which is safe:
// RS_VR_Reload always loads first, and a missing Submenu target is only a dead
// row, never a startup error.
//
// Every slider here is checked by tools/menu_lint.py on each build.
//
// A GUN PAGE'S HAND ROW OPENS ITS TYPE'S PAGE (WM_HS_<Type>, RS_VR_Reload): the hand seats
// are per kind of gun, so the pump's row opens the shotgun's. The hub pages keep
// "Your hand on each gun", which opens the reload system's type picker.
//
// SO DOES ITS AMMO ROW (WM_HA_<Type>, RS_VR_Reload 09-13 15:39, FEEL_PLAN row 3): a magazine,
// shell, cell or round in the hand and on the floor is placed per kind of gun too. The hub
// pages keep WM_MagMenu, which is now the reload system's links to all fourteen.
// ============================================================================

	Submenu "VR Weapons -- weapon set", "WM_WeaponSetMenu"

}
