// ==========================================================================
// THE WW2 SET'S MODELS -- one block per gun, binding its mesh to the prop its card names.
//
// Ships only in RS_VR_Weapons_WW2.pk3. MODELDEF blocks ACCUMULATE across archives, so this sits
// beside the base pack's without replacing anything.
//
// Seats are the base pack's per-hand defaults to start with (wm_main / wm_off): a seat belongs to
// the HAND, and every one of these wants finding in a headset anyway. PlacementCVars is deliberately
// omitted until the owner has sat with them -- a slider set nobody has tuned is worse than none.
// ==========================================================================
