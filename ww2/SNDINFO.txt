// ==========================================================================
// THE WW2 SET'S SOUNDS.
//
// A SET SHIPS ITS OWN SNDINFO the same way it ships its own MODELDEF: SNDINFO ACCUMULATES across
// archives rather than replacing, so this sits beside the base pack's instead of standing in for
// it. Nothing here may restate a name the base already owns.
//
// GUN SOUNDS ARE THIS PACKAGE'S. RS_VR_Reload carries no gun assets at all -- only the sounds no
// gun owns, the dry click, the brass and the magazine drop (its build.ps1:63). RS_Ballistics owns
// the sounds its recipes make: the flame, the brass landing, a round going past your ear. The
// gun's own voice -- its shot, its bolt, its magazine -- belongs here, with the gun.
// ==========================================================================

// THE GARAND'S EN-BLOC PING. The clip is thrown clear on the LAST ROUND rather than on a reload,
// which is why the card names it `ejectsound` -- a clip thrown clear is exactly that event, and
// tying it to a reload gesture would play it at the wrong moment.
//
// Brutal Wolfenstein's own M1SNDS/M1PING.ogg, from the same pack the models come from, so it
// travels under the same credit. Their Garand plays it the same way, out of its own states.

// ---- RELOAD AND HANDLING -----------------------------------------------------
//
// BRUTAL WOLFENSTEIN RECORDS ITS RELOADS AS AN ORDERED SEQUENCE, R1 R2 R3, not as labelled
// events -- so reload1 is 'the first thing you hear', NOT 'the magazine leaving'. They are
// named by sequence here on purpose: which one is magoutsound and which is maginsound is a
// question about the card's verbs, and the reload lane owns those. Guessing would put the
// right sound on the wrong moment, which is worse than silence because it reads as finished.
//
// ww2/dry is Brutal Wolfenstein's own DRYFIRE and serves every gun in the set.
