// ==========================================================================
// THE BLOOD SET'S SOUNDS.
//
// A SET SHIPS ITS OWN SNDINFO the same way it ships its own MODELDEF: SNDINFO ACCUMULATES
// across archives rather than replacing, so this sits beside the base pack's instead of
// standing in for it. Nothing here restates a name the base already owns.
//
// ZBLOODY HELL'S OWN, out of the mod the meshes were built for, so they travel under the same
// credit as the models. Nothing is borrowed from another set: where the mod recorded no sound
// for a step the step is silent, because a neighbour's foley standing in sounds deliberate.
//
// SOME OF THESE ARE DOOM'S OWN DMX LUMPS WITH NO FILE EXTENSION -- the engine has read that
// format since 1993 and they ship as .lmp rather than being converted. A format we do not
// recognise is not the same as a file that is not audio, which is the mistake that had this
// whole set reported as shipping four sounds when it ships hundreds.
//
// RELOAD FOLEY IS NAMED HERE BUT WIRED IN WMCARD.blood, the reload lane's file. A Weapon Card
// owns exactly one sound key, `firesound`.
// ==========================================================================
